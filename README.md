# भरोसी माली · ग्राम पंचायत अमरगढ़

यह स्टैटिक HTML, Tailwind और साधारण JavaScript की आठ पेज की वेबसाइट है। ZIP निकालने के बाद `dist/index.html` ब्राउज़र में खोलें। साइट खोलने के लिए सर्वर या खाते की ज़रूरत नहीं है। वीडियो और उपशीर्षक जोड़ने के बाद उन्हें स्थानीय सर्वर या होस्टिंग पर जाँचें।

## जानकारी कैसे बदलें

वेबसाइट की सामग्री प्रोजेक्ट की मुख्य फ़ाइल `content.json` में है। फ़ाइल UTF-8 में सहेजें और दोहरे उद्धरण चिह्न व कॉमा बनाए रखें। बदलाव के बाद `npm run build` चलाएँ। इससे `dist/` में पेज फिर बनेंगे।

| फ़ील्ड | क्या भरें |
| --- | --- |
| `name`, `place`, `office`, `tagline`, `subtitle`, `strip`, `closing`, `appeal` | नाम, स्थान, पद और शीर्षक |
| `symbol`, `pollingDate` | पुष्टि किया हुआ चुनाव चिह्न और मतदान की तारीख |
| `phone`, `whatsapp`, `formEmail` | सार्वजनिक फ़ोन, व्हाट्सऐप नंबर और फ़ॉर्म के लिए ईमेल। व्हाट्सऐप नंबर देश कोड सहित लिखें, जैसे `91XXXXXXXXXX` में X की जगह असली अंक। |
| `bio`, `portrait`, `bioPhoto` | परिचय और तस्वीरों के पथ, जैसे `assets/portrait.webp` |
| `reel` | `file` में वीडियो, `captions` में हिंदी WebVTT, `poster` में वैकल्पिक तस्वीर और `transcript` में वैकल्पिक लिखित पाठ। वीडियो और उपशीर्षक दोनों की फ़ाइलें होने पर ही प्लेयर दिखेगा। |
| `pledges`, `timeline`, `plan`, `issues` | उम्मीदवार के संकल्प, चार चरणों की रूपरेखा, क्षेत्रवार योजना और उम्मीदवार के शब्दों में गाँव की ज़रूरतें |
| `facts` | हर आँकड़े का `label`, सत्यापित `value` और सीधे स्रोत का `source` URL |
| `gallery` | हर तस्वीर का `file` और उसका हिंदी `alt` |
| `updates` | हर अपडेट में क्रम के लिए `date` (YYYY-MM-DD), दिखने के लिए हिंदी `dateLabel`, `title` और `detail` |
| `social`, `mapUrl` | सोशल लिंक के लिए `label` और `url` तथा नक्शे का पूरा लिंक |
| `siteUrl`, `shareImage` | अंतिम सार्वजनिक HTTPS पता और शेयर प्रीव्यू की तस्वीर, जैसे `assets/share.jpg`। इससे sitemap, canonical और शेयर URL बनेंगे। |

फ़ोटो, वीडियो और उपशीर्षक मुख्य `assets/` फ़ोल्डर में रखें। फ़ाइलों के छोटे अंग्रेज़ी नाम रखें। मोबाइल के लिए तस्वीरें WebP में और रील छोटे MP4 में रखें। प्रकाशित फ़ोल्डर में केवल सार्वजनिक फ़ाइलें रखें।

## फ़ॉर्म

व्हाट्सऐप नंबर सेट होने पर फ़ॉर्म व्हाट्सऐप में संदेश तैयार करता है। उसके बिना सेट किया हुआ ईमेल इस्तेमाल होता है। आगंतुक अपने ऐप से संदेश भेजता है। वेबसाइट कोई डेटाबेस नहीं रखती। फ़ोन तभी संदेश में जाता है जब संपर्क की अनुमति चुनी गई हो। वार्ड या मोहल्ला लिखना वैकल्पिक है और उसके लिए सुझाव संदेश के भीतर जगह है।

## बनाना और जाँचना

Node.js 20 या उसके बाद का संस्करण इस्तेमाल करें। Tailwind की पूरी बिल्ड के लिए पहली बार `npm install` चलाएँ। ऑफ़लाइन रहते हुए `node build.mjs` मौजूदा डिज़ाइन के लिए शामिल CSS उपयोगिताओं से पेज बना सकता है। फिर `npm run check` से पेज, लिंक, होम का क्रम और फ़ॉर्म की फ़ील्ड जाँचें।

## होस्टिंग

- **Netlify** — Git से जोड़कर बिल्ड कमांड `npm run build` और प्रकाशित फ़ोल्डर `dist` चुनें। बिना Git के तैयार `dist` फ़ोल्डर अपलोड करें।
- **Vercel** — Git प्रोजेक्ट इम्पोर्ट करें, फ़्रेमवर्क `Other`, बिल्ड कमांड `npm run build` और आउटपुट फ़ोल्डर `dist` रखें।
- **शेयर्ड होस्टिंग** — अपने कंप्यूटर पर बिल्ड चलाकर `dist/` के अंदर की फ़ाइलें और फ़ोल्डर `public_html/` या डोमेन की वेबसाइट डायरेक्टरी में अपलोड करें।

अंतिम पता मिलने पर उसे `siteUrl` में भरकर फिर बिल्ड और अपलोड करें। शेयर प्रीव्यू के लिए `shareImage` भी सेट करें। लाइव URL से फ़ॉर्म और वीडियो उपशीर्षक जाँचें।
